The affected tests run after every change. The full suite runs before every database migration, annual data load and client handover.

Every database test runs in its own transaction and rolls back, so testing never changes live figures.

Each run is recorded with its reason and evidence.

Transactional test isolation and test markers keep installation, demonstration and development checks apart.

Test stack
Python 3.14, pytest 9.1, pyodbc and SQL Server 2025, with Node.js, Flyway and headless Edge.

Independent checks
Ruff, Bandit, Vulture, SQLFluff, ESLint, the TypeScript checker, pip-audit and Gitleaks.

All figures in this repository belong to East Coast Council, a fictional demonstration council.
